# YouTube Live View Counter — Deployment Guide

## Overview
This project updates your YouTube video's title every 10 minutes to show:
**"This YouTube video has exactly X views"**

Hosted on Wasmer Edge (free tier) with automatic cron scheduling.

---

## Prerequisites
- Google account (for YouTube)
- Google Cloud account (free tier)
- Wasmer account (free tier)
- Python 3.12+ installed locally

---

## Phase 1: Google Cloud Setup (~15 min)

### Step 1: Create Project
1. Go to https://console.cloud.google.com
2. Click "Select a project" → "New Project"
3. Name it (e.g., "youtube-title-updater")
4. Click "Create"

### Step 2: Enable YouTube Data API
1. In the console, go to **APIs & Services > Library**
2. Search for "YouTube Data API v3"
3. Click on it → Click **"Enable"**

### Step 3: Create OAuth Credentials
1. Go to **APIs & Services > Credentials**
2. Click **"+ Create Credentials"** → **"OAuth client ID"**
3. If prompted, configure the OAuth consent screen:
   - User Type: **External**
   - App name: (anything, e.g., "YouTube Title Updater")
   - User support email: your email
   - Developer contact: your email
   - Save and continue through the scopes page (add `youtube` scope)
   - Add your Google account as a test user
4. Back to credentials:
   - Application type: **Desktop app**
   - Name: (anything)
   - Click **"Create"**
5. **Download the JSON** file
6. Rename it to `client_secret.json` and place it in this project folder

### Step 4: Get Your Refresh Token
```bash
# Install dependencies locally
pip install google-auth-oauthlib google-api-python-client

# Run the setup script
python setup_oauth.py
```

This will:
1. Open a browser window
2. Ask you to sign in and authorize
3. Print your **REFRESH_TOKEN** (save this!)
4. Save full token details to `refresh_token.json`

## Phase 2: Wasmer Edge Deployment

### Step 1: Create Wasmer Account
1. Go to https://wasmer.io
2. Sign up (free tier)
3. Install the CLI:
   ```bash
   curl https://get.wasmer.io -sSfL | sh
   ```
4. Login:
   ```bash
   wasmer login
   ```

### Step 2: Prepare Deployment Files
You should have these files in your project:
```
Live-yt/
├── youtube_live_title_updater.py   (main script)
├── setup_oauth.py                  (one-time OAuth setup)
├── requirements.txt                (dependencies)
├── wasmer_app.yaml                 (Wasmer config)
├── client_secret.json              (Google OAuth - keep secret!)
└── refresh_token.json              (generated by setup_oauth.py)
```

### Step 3: Deploy to Wasmer
```bash
# From the project directory
wasmer deploy
```

### Step 4: Set Environment Variables
In the Wasmer dashboard (https://my.wasmer.io):

1. Go to your app → **Settings** → **Environment Variables**
2. Add these variables:

| Variable | Value |
|----------|-------|
| `VIDEO_ID` | Your YouTube video ID (e.g., `dQw4w9WgXcQ`) |
| `REFRESH_TOKEN` | The refresh token from Step 4 of Phase 1 |
| `CLIENT_SECRET_JSON` | Contents of `client_secret.json` (as a single JSON string) |

**To get CLIENT_SECRET_JSON as a string:**
```bash
# Run this in your terminal:
python -c "import json; print(json.dumps(json.load(open('client_secret.json'))))"
```
Copy the output and paste it as the value.

### Step 5: Upload Your Video
1. Upload any video to YouTube
2. Copy the video ID from the URL:
   ```
   https://www.youtube.com/watch?v=VIDEO_ID_HERE
                                    ^^^^^^^^^^^^^^^
   ```
3. Set `VIDEO_ID` in Wasmer dashboard with this value

### Step 6: Verify
1. Check Wasmer logs: your app → **Logs**
2. You should see:
   ```
   Updated title -> "This YouTube video has exactly 123 views"
   ```
3. Wait 10 minutes and check YouTube — the title should update!

## Troubleshooting

### "Quota exceeded" error
- Check https://console.cloud.google.com/apis/api/youtube.googleapis.com/quotas
- Default: 10,000 units/day; each update costs 51 units
- At 10-min intervals: ~7,344 units/day (within limits)

### "Video not found" error
- Verify VIDEO_ID is correct
- Video must be public (not private/unlisted for API access)

### OAuth errors
- Re-run `python setup_oauth.py` to get a fresh refresh token
- Ensure test user is added in OAuth consent screen

### Title not updating
- Check Wasmer logs for errors
- Verify all environment variables are set correctly
- Ensure YouTube Data API is enabled in Google Cloud

## How It Works

```
Every 10 minutes (cron)
    ↓
Wasmer runs update_title.py
    ↓
YouTube API: GET /videos (read view count)
    ↓
YouTube API: PUT /videos (update title)
    ↓
Title: "This YouTube video has exactly 1,234 views"
```

The script only updates the title if the count has actually changed, saving API quota.
